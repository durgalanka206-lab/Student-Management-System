# CampusOS ERP

Modern Student Management & College ERP Platform.

## Features

- Student Management
- Faculty Management
- Attendance Tracking
- Results Management
- Fee Management
- Timetable Management
- Announcements
- Reports Dashboard
- Leave Requests
- Student Performance Analytics

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- Radix UI
- Recharts

## Live Demo

https://student-management-system-nu-khaki.vercel.app

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
